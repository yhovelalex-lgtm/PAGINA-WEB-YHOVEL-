# Herramientas opcionales de autoría

`mcp.example.json` es una plantilla, no una conexión activa. Los clientes MCP usan formatos y sintaxis de variables diferentes: adapta la plantilla a la documentación de tu cliente. Guarda API_KEY_21ST en el entorno local del cliente, nunca en este repositorio, en el navegador o en variables VITE_.

Servicio oficial: https://docs.21st.dev/mcp
Skill UI UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

La web está implementada con componentes propios. No contiene componentes descargados de 21st ni requiere su API para funcionar. Incorporar cualquier componente futuro requiere revisar licencia, accesibilidad y dependencias.
