|---|---|

## Criterio económico

No se activaron nuevas suscripciones, generación de pago, bases de datos ni funciones de servidor. El coste real depende del plan vigente de las cuentas y del uso; no se garantiza coste cero ilimitado.

Vercel Hobby está orientado a uso personal no comercial y sujeto a límites. Si la plataforma pasa a prestar servicios comerciales o vender acceso, revisar elegibilidad y plan antes de ese cambio. Referencia: https://vercel.com/docs/plans/hobby

21st requiere una clave y tiene cupos gratuitos; no asumir generación ilimitada. Referencia: https://docs.21st.dev/mcp

Las imágenes originales y videos pesados se conservan fuera de GitHub; solo publicar medios optimizados. Un dominio personalizado supone un coste aparte y no fue comprado.
