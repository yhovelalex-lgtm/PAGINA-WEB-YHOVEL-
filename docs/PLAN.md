## Fase 3 — Gestión ampliada, solo si es necesaria
- [ ] Evaluar CMS con autenticación para subir imágenes y publicar sin entrar a GitHub.
- [ ] Considerar Supabase para usuarios, permisos y contenido mutable si el flujo Git deja de ser suficiente.
- [ ] Acceso común entre aplicaciones: proyecto separado con permisos definidos; no implica compartir datos automáticamente.
- [ ] Dominio personalizado, solo si se decide asumir su coste.

## Reglas

Registrar fallos y mejoras en Issues usando las plantillas. Cada tarea debe indicar sección, resultado esperado y cómo comprobarlo. No activar suscripciones ni consumir APIs de pago sin una decisión explícita. No mezclar credenciales de servicios con contenido público.
